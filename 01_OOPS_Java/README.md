## 📋 Topic Checklist

### Unit 1: Introduction to Java & Fundamentals
- [ ] JVM, JRE, JDK architecture & Bytecode execution
- [ ] Primitive data types, Literals, Variables, and Type Casting
- [ ] Operators, Expressions, and Operator Precedence
- [ ] Control Statements: if-else, switch-case, loops (for, while, do-while, for-each)
- [ ] Command line arguments and basic I/O with Scanner

### Unit 2: Core OOP Concepts & Classes
- [ ] Class, Object, Instance Variables, and Method anatomy
- [ ] Constructors: Default, Parameterized, Copy, Constructor Overloading, Constructor Chaining
- [ ] `this` keyword: Uses and subtleties
- [ ] Memory Allocation: Stack vs Heap, Garbage Collection mechanism, `finalize()`
- [ ] `static` keyword: Static variables, methods, blocks, and static imports

### Unit 3: Inheritance & Polymorphism
- [ ] Types of Inheritance (Single, Multilevel, Hierarchical; why Multiple Inheritance is disallowed for classes)
- [ ] Method Overloading (Compile-time polymorphism)
- [ ] Method Overriding & Dynamic Method Dispatch (Runtime polymorphism)
- [ ] `super` keyword (accessing parent constructors, variables, methods)
- [ ] `final` keyword (final variables, methods, and classes)
- [ ] Abstract Classes vs Interfaces
- [ ] Interface evolution: Default methods, static methods, and private methods

### Unit 4: Packages & Exception Handling
- [ ] Packages: Creating, importing, classpath configuration
- [ ] Access Specifiers: `private`, `default`, `protected`, `public`
- [ ] Exception Hierarchy (`Throwable`, `Error`, `Exception`, Checked vs Unchecked)
- [ ] `try`, `catch`, `finally` constructs & multi-catch blocks
- [ ] `throw`, `throws` keywords, and propagating exceptions
- [ ] Custom / User-defined Exception classes

### Unit 5: Multithreading & Concurrency
- [ ] Thread lifecycle and thread states (New, Runnable, Blocked, Waiting, Timed Waiting, Terminated)
- [ ] Creating threads: extending `Thread` class vs implementing `Runnable`
- [ ] Thread priorities, `sleep()`, `join()`, `yield()`, and daemon threads
- [ ] Synchronization: Critical section, synchronized methods vs synchronized blocks
- [ ] Inter-thread communication: `wait()`, `notify()`, `notifyAll()`
- [ ] Deadlock condition, prevention, and thread safety

### Unit 6: Java Collections Framework & Generics
- [ ] Introduction to Collections hierarchy & Generics (`<T>`, wildcards `? extends / super`)
- [ ] `List` Interface: `ArrayList`, `LinkedList`, `Vector`
- [ ] `Set` Interface: `HashSet`, `LinkedHashSet`, `TreeSet` (Comparable vs Comparator)
- [ ] `Queue` & `Deque`: `PriorityQueue`, `ArrayDeque`
- [ ] `Map` Interface: `HashMap`, `LinkedHashMap`, `TreeMap`, Internal working of `HashMap`
- [ ] Iterators: `Iterator`, `ListIterator`, `Enumeration`

### Unit 7: I/O Streams & Serialization
- [ ] Byte Streams (`FileInputStream`, `FileOutputStream`)
- [ ] Character Streams (`FileReader`, `FileWriter`, `BufferedReader`, `BufferedWriter`)
- [ ] Serialization & Deserialization: `Serializable` interface, `ObjectOutputStream`, `ObjectInputStream`
- [ ] `transient` and `volatile` keywords

### Unit 8: Modern Java (Java 8+ Features)
- [ ] Lambda Expressions & Functional Interfaces (`@FunctionalInterface`, `Predicate`, `Function`, `Consumer`, `Supplier`)
- [ ] Stream API: Intermediate operations (`filter`, `map`, `sorted`) & Terminal operations (`collect`, `forEach`, `reduce`)
- [ ] `Optional` class to handle `NullPointerException`
