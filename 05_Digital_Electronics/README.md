## 📋 Topic Checklist

### Unit 1: Number Systems, Codes & Binary Arithmetic
- [ ] Number Systems: Binary, Octal, Decimal, Hexadecimal conversions
- [ ] Binary Arithmetic: Addition, Subtraction using 1's and 2's Complement
- [ ] Floating Point Representation (IEEE 754 Single & Double precision)
- [ ] Binary Codes: BCD (8421), Excess-3, Gray Code (Binary to Gray & vice-versa)
- [ ] Error Detection and Correction: Parity Bit, Hamming Code (generation and error correction)

### Unit 2: Boolean Algebra & Logic Gate Minimization
- [ ] Basic Logic Gates (AND, OR, NOT) and Universal Gates (NAND, NOR)
- [ ] Special Gates: XOR, XNOR, and parity generators
- [ ] Boolean Theorems, Postulates, and De Morgan's Laws
- [ ] SOP (Sum of Products) and POS (Product of Sums), Minterms ($m$) and Maxterms ($M$)
- [ ] Karnaugh Map (K-Map) Minimization: 2, 3, 4, and 5 variables
- [ ] Don't Care conditions ($d$) in K-Maps
- [ ] Quine-McCluskey (Tabular) Minimization Method

### Unit 3: Combinational Logic Circuits
- [ ] Adders and Subtractors: Half Adder, Full Adder, Half Subtractor, Full Subtractor
- [ ] Parallel Binary Adder, Carry Lookahead Adder (CLA)
- [ ] BCD Adder
- [ ] Magnitude Comparator (1-bit, 2-bit, 4-bit)
- [ ] Multiplexers (MUX): 2:1, 4:1, 8:1, 16:1, Implementing Boolean expressions using MUX
- [ ] Demultiplexers (DEMUX) & Decoders: 2:4, 3:8, BCD to 7-Segment Decoder
- [ ] Encoders: Priority Encoders
- [ ] Code Converters: BCD to Excess-3, Binary to Gray

### Unit 4: Sequential Logic Circuits & Flip-Flops
- [ ] Latches vs Flip-Flops, Clocking schemes (Level-triggered vs Edge-triggered)
- [ ] SR Latch using NAND / NOR gates
- [ ] Flip-Flops: SR, JK, D, and T Flip-Flop
- [ ] Race-around Condition in JK Flip-Flop & Master-Slave JK Flip-Flop
- [ ] Characteristic Equations, Characteristic Tables, and Excitation Tables of all Flip-Flops
- [ ] Flip-Flop Conversions (e.g., SR to JK, JK to D, T to D)

### Unit 5: Registers & Counters
- [ ] Shift Registers: SISO, SIPO, PISO, PIPO
- [ ] Universal Shift Register & Bidirectional Shift Register
- [ ] Asynchronous (Ripple) Counters: Up Counter, Down Counter, Modulo-N Counters
- [ ] Synchronous Counters: Design using Flip-Flops, Up/Down Synchronous Counters
- [ ] Ring Counter and Twisted Ring (Johnson) Counter

### Unit 6: Finite State Machines (FSM) & Synchronous Design
- [ ] Mealy vs Moore State Machine Models
- [ ] State Diagram, State Table, State Reduction, and State Assignment
- [ ] Design of Sequence Detectors (Overlapping vs Non-overlapping sequences)
- [ ] Glitches and Hazards: Static, Dynamic, and Essential Hazards

### Unit 7: Semiconductor Memories & Programmable Logic
- [ ] Memory Classification: RAM (SRAM vs DRAM), ROM (PROM, EPROM, EEPROM, Flash)
- [ ] Programmable Logic Devices: PROM, PLA (Programmable Logic Array), PAL (Programmable Array Logic)
- [ ] CPLD and FPGA architectural fundamentals

### Unit 8: Logic Families & Converters (D/A & A/D)
- [ ] Logic Families: TTL, CMOS, ECL characteristics (Propagation delay, Fan-in, Fan-out, Noise Margin, Power dissipation)
- [ ] Digital-to-Analog Converters (DAC): Weighted Resistor DAC, R-2R Ladder DAC
- [ ] Analog-to-Digital Converters (ADC): Flash ADC, Successive Approximation ADC (SAR), Dual Slope ADC
