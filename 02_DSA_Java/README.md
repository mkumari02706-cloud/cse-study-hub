## 📋 Topic Checklist

### Unit 1: Analysis of Algorithms & Mathematical Foundations
- [ ] Asymptotic Notations: Big-O, Big-Omega, Big-Theta, Little-o, Little-omega
- [ ] Time and Space Complexity calculations for iterative and recursive functions
- [ ] Solving Recurrences: Substitution Method, Recursion Tree Method, Master Theorem (all cases)
- [ ] Amortized Analysis basics (Aggregate method, Accounting method, Potential method)

### Unit 2: Arrays, Strings & Two-Pointer Patterns
- [ ] Array representation in memory, row-major and column-major order
- [ ] Prefix Sum and Difference Arrays
- [ ] Two Pointers (opposite ends, same direction)
- [ ] Sliding Window (Fixed size, Variable size / Dynamic window)
- [ ] Kadane's Algorithm for Maximum Subarray Sum
- [ ] String matching algorithms: Naive, KMP (Knuth-Morris-Pratt), Rabin-Karp

### Unit 3: Linked Lists
- [ ] Singly Linked List: Insertion, Deletion, Search, Traversal
- [ ] Doubly Linked List & Circular Linked List
- [ ] Fast and Slow Pointer Technique (Floyd's Cycle-Finding Algorithm)
- [ ] Reversal of a Linked List (Iterative & Recursive)
- [ ] Merging two sorted lists & Merge Sort on Linked Lists

### Unit 4: Stacks and Queues
- [ ] Stack implementation using Arrays and Linked Lists
- [ ] Applications: Infix to Postfix/Prefix conversion, Expression Evaluation
- [ ] Monotonic Stack pattern (Next Greater Element, Largest Rectangle in Histogram)
- [ ] Queue, Circular Queue, and Deque implementations
- [ ] Implementation of Stack using Queues and Queue using Stacks

### Unit 5: Searching & Sorting Algorithms
- [ ] Linear Search vs Binary Search (lower bound, upper bound, rotated sorted array)
- [ ] Comparison Sorts: Bubble Sort, Selection Sort, Insertion Sort
- [ ] Divide & Conquer Sorts: Merge Sort, Quick Sort (Lomuto vs Hoare partitioning)
- [ ] Non-Comparison Sorts: Counting Sort, Radix Sort, Bucket Sort
- [ ] Stability, in-place behavior, and best/average/worst case analysis

### Unit 6: Trees & Binary Search Trees (BST)
- [ ] Tree terminology, properties of Binary Trees (Full, Complete, Perfect, Balanced)
- [ ] Tree Traversals: Inorder, Preorder, Postorder (Recursive & Iterative), Level-Order
- [ ] Height, Diameter, Maximum Depth, Lowest Common Ancestor (LCA)
- [ ] Binary Search Tree (BST): Search, Insertion, Deletion, Inorder Successor/Predecessor
- [ ] Balanced BST concepts: AVL Trees (Rotations: LL, RR, LR, RL), Red-Black Trees overview

### Unit 7: Priority Queues & Heaps
- [ ] Binary Heap properties (Min Heap & Max Heap representation in array)
- [ ] Heap Operations: `insert`, `extractMin`/`extractMax`, `heapify` (O(N) build heap)
- [ ] Heap Sort algorithm
- [ ] Top K Frequent Elements, Merge K Sorted Lists, Find Median from Data Stream

### Unit 8: Graphs
- [ ] Graph representations: Adjacency Matrix vs Adjacency List
- [ ] Graph Traversals: Breadth First Search (BFS), Depth First Search (DFS)
- [ ] Cycle Detection in Undirected and Directed Graphs
- [ ] Topological Sorting: Kahn's Algorithm (BFS) and DFS-based
- [ ] Shortest Path Algorithms: BFS for unweighted, Dijkstra's Algorithm, Bellman-Ford, Floyd-Warshall
- [ ] Minimum Spanning Trees (MST): Kruskal's (with Disjoint Set Union / Union-Find) and Prim's Algorithm

### Unit 9: Dynamic Programming & Greedy Algorithms
- [ ] Memoization (Top-down) vs Tabulation (Bottom-up)
- [ ] 1D DP: Climbing Stairs, Fibonacci, House Robber
- [ ] 0/1 Knapsack problem and variants (Subset Sum, Equal Partition)
- [ ] Unbounded Knapsack (Coin Change, Rod Cutting)
- [ ] Longest Common Subsequence (LCS) & Longest Increasing Subsequence (LIS)
- [ ] Matrix Chain Multiplication (MCM)
- [ ] Greedy Algorithms: Activity Selection, Fractional Knapsack, Huffman Coding

### Unit 10: Backtracking & Divide and Conquer
- [ ] Backtracking template & State Space Trees
- [ ] N-Queens Problem
- [ ] Sudoku Solver
- [ ] Subset Generation, Permutations, Combinations
